# File-backed weighted global parsing

E0026 established exact boundary-conditioned shortest paths. The Rust implementation uses 1 MiB computational partitions, each with a D-cost right boundary vector and up to D-1 bytes of right halo, D=max dictionary expansion. Backward pass computes all boundary vectors; forward pass recomputes local choices and emits roots crossing partitions without resetting model or dictionary. Uses u64 costs; the archive remains IXG2, not separately compressed blocks. A histogram pass per candidate derives exact serialized cost, and final emission reconstructs the selected path. Greedy is retained if no candidate is smaller. For Huffman four smoothed fixed-weight iterations replicate E0024; they are not globally optimal joint code/parse. Memory O(B+D ceil(L/B)+K), excluding bounded dictionary and buffers. No full-target result yet. CI E0028 verifies byte-identical archives against the bounded in-memory parser and exact reconstruction, including small-block exhaustive tests. File must remain stable across passes; hash checked by experimental harness.
