# Larger dictionary ablation

E0049 tests the established third-order model, changing only training coverage and rule budget. Baseline 256 KiB/8192 rules, 512 KiB/8192 and 512 KiB/16384; 8 sampled regions 0,30M,40M,80M,33M,60M,70M,90M, all disjoint from measured held-out regions. Same greedy parsing and mode 9 coding. Same-sample rule prefixes are nested; verify dictionary prefix byte equality. Rule cap doubled, sample cap doubled, old archive semantics preserved. Larger dictionary reduces number of roots potentially, but wider rank path and more sparse contexts increase modeling cost. Full charged archives and strict decoder equality measured; no gain assumed. Order-two tagged key bound proven: maximum (257^2)*32768 < 2^32. Memory cost grows with dense order-one table. Training repeated scans are slow; measure actual RSS and runtime. Scale only if justified.
