# Next design: global arithmetic dictionary with streamed roots

C07 E0022 demonstrates authentic savings and substantially stronger synthetic reuse after crossing width barriers; the 16 KiB authentic archives remain larger than gzip. Naively rescanning a billion-byte root list 512 times is not the next experiment.

Candidate IXG2: train a bounded topological concatenation DAG on an explicitly recorded small sample (the sample is not side information at decode time: store the entire resulting alphabet and rules in the archive). Extend alphabet to all 256 bytes so any unseen digit has a literal. Build a trie from rule expansions with explicit expansion-length and total-memory caps. Encode the full byte stream as references to global DAG nodes, using bounded lookahead and deterministic longest match or dynamic programming on a bounded window. A root stream represents the entire integer by repeated exact radix concatenation. Include original byte length, rule list, framing, root IDs and any entropy model; do not count sample availability as free decoder information. Distinguish fixed model training, greedy parsing and code-length optimization. No result yet.

Milestones: implement Rust reference with isolated archive-only decoder and full metadata accounting; first test real slices and a larger held-out region; compare fixed-width and explicitly charged variable-length roots. Scale to the whole corpus only after tests and memory/runtime measurements. A global single grammar is a whole-stream description; independently trained blocks are blockwise and must not be mixed in frontier entries. Grammar compression and dictionary parsing are established prior art; retain the arithmetic interpretation without claiming novelty.
