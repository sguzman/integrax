# Sparse correction operand cost

With known length m, a single nonzero byte correction has exactly 255m possibilities, even for overlap: a fixed prior history and positive distance define a bijection between residual vectors and generated digits by sequential inversion. For uniform position and residual, entropy log2(255m); equiprobable eight-bit fields cost 16 bits. Real residuals may cluster around early positions, ASCII substitutions or small modular differences. Mode19 learns position and residual marginal distributions via two independent binary prefix trees (2048 bytes of counters). No additional archive metadata and identical token selection to mode18. This isolates operand coding cost but does not account for possible dependence between position and residual.
