# Global DAG root stream cost

For a fixed dictionary, each root is an exact arithmetic concatenation term. A greedy longest match minimizes neither root count globally nor Huffman bit cost; it is a deterministic bounded streaming parser. At a fixed parsed sequence of R roots, dictionary size n rules, alphabet size K=256+n, fixed-width cost is 15+4n+ceil(R ceil(log2 K)/8) bytes. Huffman mode costs 15+4n+sum_i v(f_i)+ceil(sum_i f_i l_i/8), with canonical varint length v, counts f, deterministic Huffman code length l. Both include the entire shared dictionary; training sample is only an encoder input. Huffman minimizes binary prefix-code weighted length for these counts, not total archive length across all possible models/parses. A one-symbol stream uses a zero-bit code because original length and counts determine repetition.

The comparison isolates coding of the same root sequence from dictionary selection and parsing. Next opportunities are charged root entropy models and shortest-path parsing for fixed costs; dynamic programming recurrence cost[pos]=min over matching roots (cost[pos+len]+code_length) is exact on a finite window but globally optimal parsing needs boundary conditions and may not optimize subsequent learned frequencies. No novelty claim. Full-corpus scale requires measured throughput and isolated verification.
