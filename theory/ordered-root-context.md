# Ordered root values and suffix contexts

The training-order identifier of a grammar root is arbitrary with respect to its arithmetic expansion. Lexicographic sorting of its expanded base-256 digit string (tie by original identifier) is a deterministic bijection derivable from the complete dictionary. It incurs no permutation bytes and does not change the greedy parse, expansion or exact distribution entropy H(R). It changes the partition of root values among prefix-tree leaves. A finite adaptive binary-prefix model shares counts among leaves with common rank prefix; ordering by expansion may group similar digit strings, reducing prediction regret, or may hurt if it destroys a useful frequency ordering. No entropy reduction theorem follows merely from relabeling.

A last-two-byte context models information in the actual expanded integer rather than in the previous rule's arbitrary identifier. The full table would have 257^2*2^w entries, so a fixed 2^21 tagged table stores a bounded working set. Key identity prevents accidental count sharing: collisions evict and reset the corresponding context, not merge it. A missing context uses the one-byte estimate; a present context borrows eight fractional observations from it. The local and suffix weights remain positive, total <=4103*4095 <2^25, within the interval coder's safe subdivision bound. Both sides update identically; maximum key <2^31 for K<=8448. Table entries contain u32 tag and two u16 counters; nominal added state 16 MiB. Fixed parameters selected before measurements; no claim of optimality.
