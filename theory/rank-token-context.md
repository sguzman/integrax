# Rank-token context specificity

A maximal-zero-run tokenization loses no information: every nonzero MTF rank is literal, and every maximal zero stretch has a positive length. The mode4 predictor indexes all three binary-decision families by a coarse magnitude bucket of the previous token. A zero-run token resets the bucket to zero regardless of the preceding rank. Mode5 retains two successive token buckets, allowing decisions after a run to depend on the rank magnitude before the run. Mode6 uses the exact previous rank rather than its bucket, giving a finer one-token context but no extra temporal history. Contexts are functions solely of decoded tokens; no boundaries or model parameters are hidden. With c contexts, the model has c*(256+1+25) adaptive count pairs, each pair two u16 counts. Mode4 c=9, mode5 c=81, mode6 c=256. A richer model can reduce conditional entropy while increasing estimation regret; neither alternative guarantees savings. All transforms and parse decisions are unchanged. E0076 compares mode4/5/6 on the same three authentic regions and checks mode4 archive hash regression, exact reconstruction and append rejection. The existing full IXB2 trial remains frozen at mode4. No new full run unless measured evidence warrants it.
