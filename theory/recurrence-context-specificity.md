# Recurrence context specificity

A four-digit suffix defines a relatively broad equivalence class of earlier endpoints. A longer suffix partitions this class into smaller classes, potentially avoiding common short contexts whose continuations differ. The finer class may omit useful matches whose preceding digits differ; with a finite direct-mapped table, different key hashes also change evictions, so candidate sets are not guaranteed nested in the actual implementation. The two-candidate predictor for each class remains deterministic from the decoded prefix, with exact full-key tags and charged selector. Compare four-, six- and eight-digit contexts at equal 1 MiB window, 2^20 slots, two endpoints, threshold 16 and identical dictionary/root model. A u64 full key fits the existing 16-byte entry layout on 64-bit targets; measure RSS rather than assuming allocation layout. Model flag/selector probabilities remain conditioned on final digit. No new distance or context bytes transmitted except the mode byte. E0062 tests whether fewer false predictions and longer copies outweigh loss of coverage. Report charged archive, copies, alternate selections and timings. No optimality or novelty claim.
