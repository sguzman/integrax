# Arithmetic root decision geometry

The root alphabet is a finite set of charged arithmetic expressions. A binary prefix tree partitions that set; the chain rule factors a probability of any root as a product of conditional branch probabilities. Any full binary tree with K leaves has K-1 internal nodes (count edges, or inductively join two subtrees). The fixed-width rank tree used previously has unused leaves when K is not a power of two. A median-count split produces a complete binary tree with maximum depth ceil(log2 K), removing impossible branch decisions. A digit-aligned split first partitions by the eight bits of the initial expanded byte, then balances each subrange. Every first-byte group is nonempty because all literals exist; hence all first-eight-level branches are nonempty. This tree gives a deterministic factorization P(root|context)=P(first digit|context) P(root|first digit,context), with a binary factorization within each factor. Preorder indices are unique and <K<=stride, so the existing tagged context key bounds remain valid. Both trees derive entirely from the dictionary; no side information beyond mode byte.

In an ideal fully learned model every bijective factorization achieves the same entropy. With finite, bounded adaptive counters, tree shape can affect learning, evictions and regret. Grouping by first byte may expose linguistic structure, but uneven group sizes can lengthen some paths. Median tree removes impossible branches but may disrupt useful shared contexts.
