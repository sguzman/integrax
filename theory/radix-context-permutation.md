# Reversible context permutation of radix digits

Represent N as a fixed-length base-256 digit word x. Sorting its cyclic rotations induces a permutation of positions; their preceding digits form the last column L. The primary row p locates the original rotation. Each byte b induces a stable occurrence-rank matching between L and the sorted first column F: LF(i)=sum_{a<b}count(a)+rank_b(i), zero-based rank. Inverse traversal from p writes digits backwards. Equal rotations are indistinguishable as words, so stable tie ambiguities do not affect the reconstructed periodic word; canonical encoding orders equal rotations by start index. This is the established Burrows–Wheeler transform, not a new theorem. MTF is a reversible online rank map; run framing charges zero-run lengths explicitly. The permutation may concentrate local symbol distributions, but it does not remove information: p and L must be preserved.
