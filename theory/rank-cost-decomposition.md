# Rank and run empirical cost decomposition

For a fixed BWT/MTF sequence and maximal zero-run parse, each token emits a flag and either a nonzero rank or a positive run length. Let c be the causal context for that token. For each field f, the diagnostic gathers counts n(c,f,v) and computes E_f=sum_{c,v} n(c,f,v) log2(n(c,f)/n(c,f,v)). Empty counts contribute zero. For exponent k=floor(log2 length), unary exponent decisions with independent static probabilities have exactly E_exponent bits of empirical negative log likelihood: this follows by factoring the categorical distribution along the unary prefix tree. Mode4–6 suffixes are equiprobable, costing exactly sum k bits before arithmetic rounding. The empirical oracle E_flag+E_rank+E_exponent+sum k is an in-sample descriptive comparator for the current factorization, not a realizable archive size: it assumes decoder access to fitted counts and does not charge them. Nor is it a universal lower bound on coding cost; sequence-dependent predictors can outperform it. The difference E_exponent+sum k-E_length equals sum over contexts and exponents of conditional uniform-code excess and is nonnegative because at most 2^k lengths share exponent k. It estimates the potential benefit of a better within-exponent length model, not guaranteed savings. Actual complete frame size is measured by the existing encoder, and independently checked via CLI encode/decode and SHA-256. E0078 uses fresh offsets 123456789,456789123,900000000 (4 MiB each), distinct from prior E0052 and enwik8 regions. Modes 4/5/6 share one transform in the diagnostic; external encodes repeat it to confirm archive sizes. No new wire format. Use the result to select at most one substantial next improvement, not to claim an entropy limit or novelty.
