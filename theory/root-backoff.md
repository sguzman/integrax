# Decoder-derived hierarchical root probabilities

Local context counts split observations among 257 contexts. A cold context may have little evidence even when the unconditional root-prefix distribution is strongly biased. Mode 5 uses the global empirical predictive distribution as a fractional prior on the local model. If local total n, zero count c0, global total g and zero count g0, then p0=(c0+32*g0/g)/(n+32). The corresponding exact integer interval weights are c0*g+32*g0 and (n+32)*g. This is a convex mixture of local and global probabilities, with local weight n/(n+32). It is not an exact Bayesian posterior because both estimates are updated and rescaled and observations overlap. At large local count it approaches the local model; at cold start it borrows global information. All counters are determined by the decoded prefix, no side tables.

Positive counts and totals <=4095 imply 0<zero<total<=4127*4095<2^25. The arithmetic interval range before each decision is greater than 2^30 after E1/E2/E3 renormalization, so both integer subdivisions are nonempty. Products fit in u64 (<2^57); rescale preserves positivity. Unit tests include a new-context borrowing check. The mode adds at most 65536 bytes global table for the largest dictionary.
