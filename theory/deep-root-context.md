# Deeper predictive context ablation

E0041 established useful second-order context and rank ordering. Two possible extra predictors represent different information: the last three reconstructed base-256 digits (mode 9), or the ID of the previous arithmetic expression (mode 10). The latter can retain token-boundary and long expansion information not captured by a short digit suffix. Neither is guaranteed to help: rare contexts, collisions and insufficient evidence may increase predictive regret. Both extend the same mode 7 parser, ordering and lower-order model, use equal-sized tagged tables and borrow a fixed eight pseudo-observations from order two. For integer interval safety, quantize the lower-order probability to a positive 12-bit numerator; then total <=4103*4096. All context state is deterministic at decode, no transmitted table. Nominal additional memory 16 MiB on the usual 64-bit Rust layout (measure actual RSS). E0044 compares both extensions against mode 7 on the same held-out data. Fixed choices made before results, no global-optimality or novelty claim. Do not extrapolate or launch another full-corpus run until observed improvement.
