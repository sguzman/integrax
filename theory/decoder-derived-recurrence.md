# C11 — Decoder-derived substring recurrences

Let a_i be the reconstructed base-256 digits in stream order. Given a known preceding context of four digits, choose the most recent matching context retained in a deterministic tagged table. Its endpoint q determines distance d=i-q. A recurrence token (flag=1,length m) specifies a_{i+j}=a_{i+j-d} for 0<=j<m, permitting overlap. Since d>0, induction makes every referenced digit available before its use. With nonoverlapping source, the new block equals an earlier radix substring; with overlap it is a prefix of a periodic geometric expansion of a d-digit seed. This combines prior C02 geometric structure with C07 shared arithmetic expressions, using the decoded prefix as a dynamic source of expressions. The distance is not free side information: it is uniquely computed from already decoded digits, table state and fixed format rules. Flag and length are actually entropy coded, including misses and metadata. Collisions reset the tagged entry, never silently substitute an unequal context. The candidate is not guaranteed to match; the encoder verifies every copied digit. The decoder needs no future input or original corpus.

The scheme is related to LZP/LZ77 and predictive dictionary coding, not a novel theorem. Unlike a general LZ77 distance search, one candidate is predicted for each context, and no distance is sent. A 1 MiB ring and tagged table bound memory; length 16..256 and overlap are exact. Root model counts update only for coded decisions; its byte suffix always advances. The copy flag is coded only when a candidate exists, learned by final byte; length currently costs eight bits. This is a deliberately bounded first test, not an optimal parser. E0053 compares mode 12 with mode 13 at two thresholds, using exact strict decoding and full archive accounting. Measure copy coverage and root reduction; if gains justify, improve predictor or length model. No full-target claim until isolated verification.
