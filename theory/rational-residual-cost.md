# C05 — Normalized rational residuals

For a length L byte string let S=256^L and 0<=N<S. For any reduced 0<=p<=q, q>0, set r=N-floor(Sp/q). Then (L,p,q,r) determines N exactly. IXR2 charges the serialized numerator, denominator, sign, residual, original length and framing. In contrast with C02 exact periodic byte templates, denominators can induce bit-level periodicity and non-byte-aligned digit patterns; no period must be explicitly stored. This is a standard rational-expansion property, not a new theorem.

For a convergent p_j/q_j of x=N/S with next denominator q_(j+1), the classical continued-fraction inequality for a finite rational is |x-p_j/q_j|<=1/(q_j q_(j+1)). Consequently |r| <= S/(q_j q_(j+1))+1. The terminal convergent is exact and has residual zero. This does not ensure net savings: for generic x of constant magnitude, numerator and denominator together cost about 2 log2 q bits and typical residual width is about log2 S-2 log2 q if successive denominators are comparable. The leading costs then approximately cancel before metadata. Large partial quotients or exceptional near-rational structure are the opportunity. The usual Legendre sufficient condition |x-p/q|<1/(2q^2) implies p/q is a convergent; in our framing a sufficient residual condition is 2q^2 (|r|+1)<S. These established results justify the search but do not characterize all size-optimal candidates.

For fixed denominator bound Q and residual magnitude R, at most (2R+1)*sum_{q=1}^Q(q+1) normalized representations exist before enforcing reduced fractions or distinctness. Thus for uniform N on [0,S), coverage fraction <=min(1,(2R+1)Q(Q+3)/(2S)). This simple union count is an upper bound even with exhaustive p,q search, not an estimate for enwik9. To compress, residuals must be atypically small relative to the charged parameter sizes, or those parameters must admit additional structure.

Reference search enumerates exact Euclidean convergents with cap 1024 denominator bits / 1024 steps; it does not claim exhaustive optimization of rational descriptions. Consider semiconvergents only if data demonstrates an opportunity or a tighter theorem justifies cost. E0013 tests exact adjacent determinant identities, the finite-rational approximation inequality and full terminal reconstruction on 1024 small inputs. Literature review (classical continued fractions, rational radix expansions, Diophantine approximation) remains necessary before novelty claims.
