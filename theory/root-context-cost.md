# Root context and hybrid accounting

Given a deterministic shared dictionary D and parsed root sequence R=(r_1,...,r_m), expansion gives an exact ordered concatenation. The previous Huffman model charges a code for each root independently. In an ideal empirical first-order context model the payload entropy changes from m H(R) to m H(R_i|R_{i-1}), up to initial-root convention; the difference is m I(R_i;R_{i-1}) >= 0. This is potential model gain, not a guaranteed archive gain: counts, adaptation, smoothing, coder termination and dictionary all cost bytes. A larger dictionary changes the parse and can increase context sparsity. Do not compare entropy estimates to actual archive sizes without stating the distinction.

First measure conventional gzip and xz on the complete arithmetic archive in fixed-bit, aligned u16 and Huffman forms. Aligned IDs preserve token byte boundaries; fixed-bit packing reduces raw size but can obscure alignment; Huffman reduces independent symbol entropy but may hide repeated substrings. All three are exact, self-contained. Outer coding includes the dictionary, headers and backend framing; compare against the same backend directly on original bytes. An outer-compressed arithmetic archive belongs to the hybrid track. Decoder executable costs remain separate, no contest claim. Established entropy/dictionary theory; no novelty claim.
