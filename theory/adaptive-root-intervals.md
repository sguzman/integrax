# Native adaptive binary root intervals

For a root alphabet of K symbols, encode w=ceil(log2 K) bits per symbol through a prefix tree. Conditional bit probabilities multiply to a distribution over leaves (including unused IDs). Binary counts initialized at (1,1), updated deterministically after each observed decision and rescaled at total 4096, yield exact integer interval probabilities. A context can be the final byte of the previously expanded root (256 possibilities plus start), because the decoder has reconstructed it before the next decision. This requires no external probability table. The encoded path probability is a product of rational bit probabilities; log diagnostics sum negative log2 of each conditional probability. Actual bytes include finite interval rounding, termination and complete dictionary header. No uniform-input compression guarantee. Adaptive context modeling is established prior art.

Mode 3 measures unconditional adaptive root modeling; mode 4 measures context sensitivity while keeping all other aspects matched. Maximum count table allocation at K=8448, w=14, is 257*16384*4=16,842,752 bytes for contextual mode, plus trie and buffers. Every root takes w arithmetic decisions. It may be much slower than Huffman. Context partitioning can worsen results on short inputs due to cold-start dilution; bitwise factorization and rescaling are modeling choices, not a global optimum. The tested greedy parse need not be optimal under adaptive probabilities. Archive checksums/strict canonical termination are not in this prototype. Test held-out samples before committing full-corpus resources.
