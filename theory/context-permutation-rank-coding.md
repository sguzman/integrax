# Context permutation rank coding

The BWT preserves the digit histogram, so order-zero empirical entropy H0(L)=H0(x); no zero-order improvement follows merely from permuting digits. Sorting by a fixed length-k following context partitions the last column into contiguous groups, whose summed within-group zero-order empirical entropy equals the cyclic conditional predecessor entropy H(a_i | a_{i+1}..a_{i+k}). Group boundaries and distributions are not free. MTF replaces symbols with reversible local ranks; a stream with clustered symbols produces many rank-zero values. Native IXB1 modes 3/4 code ranks with adaptive binary prefix trees indexed by a nine-way previous-rank magnitude bucket. Mode4 separately codes maximal zero runs by a learned unary exponent and exact binary remainder. Its length description is prefix-free for any bounded positive length. No counts or hidden context boundaries transmitted. All costs are in actual arithmetic payload and 17-byte frame. This is a conventional BWT/MTF arithmetic codec experiment, not a new compression theorem. E0072 compares both native modes on the E0071 regions, with exact reconstruction and append rejection. Reuse IXG2 interval implementation; independent rank arithmetic verification still pending. Bounded memory/time; full blockwise track only if compelling authentic results.
