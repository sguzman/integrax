# C14 — Root-conditioned arithmetic descriptions

Mode 20 holds the mode15 dictionary, recurrence candidates, parse, tree and suffix models constant. Each root-tree branch additionally observes the identity of the most recent explicitly coded root (sentinel k initially; recurrence copies leave that identity unchanged). The tagged cell key is previous_root * stride + node + 1, with the existing deep hash and a separate 2^20-cell direct-mapped table. Collisions evict rather than merge. For a matching cell with positive counts a,b and existing suffix probability z/n, quantize q=clamp(floor(4096z/n),1,4095). Predict zero with (4096a+16q)/(4096(a+b+16)). Otherwise retain the original suffix prediction exactly. The numerator is strictly between zero and denominator since a,b>=1 and 0<q<4096; denominator <=(4095+16)*4096. Update both models after each coded root bit, with existing count rescaling. No transmitted model or parse change. This is a fixed pseudo-count mixture, not a claim of Bayesian optimality or novel context mixing. Related work: [Mahoney, Adaptive Weighing of Context Models for Lossless Data Compression](https://repository.fit.edu/ces_faculty/166/). Empirical falsifier: no consistent complete-archive gain on matched samples. Extra model storage ~16 MiB on common 64-bit Rust layouts; measure RSS. Old modes retain their exact logic; new mode is intentionally incompatible with old decoders.
