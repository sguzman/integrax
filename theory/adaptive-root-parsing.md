# Adaptive predictive-cost parsing

The exact arithmetic dictionary permits multiple decompositions of a given digit sequence. For every matching root r at position i, let p(r | S) be the current model probability, the product of binary conditional probabilities along its rank path, with decoder-derived state S. Its instantaneous ideal cost is -log2 p(r | S). Longest match minimizes neither this cost nor the final archive size.

E0047 compares the greedy longest match with three encoder-only heuristics that minimize (-log2 p(r | S) + lambda)/length(r), lambda in {0,2,8} bits per root. Ties prefer longer expansion then lower ID. Each candidate is scored without updating the live model; all its bit decisions use distinct prefix nodes, so the instantaneous cost equals that of encoding this root before adaptation (aside from integer interval rounding). Once selected, encode the root and update the state normally. The penalty encourages longer expressions but is not transmitted or added to the interval. No change to mode 9 decoding, dictionary, or frame; every chosen sequence expands exactly. The streaming parser uses the same maximum-expansion lookahead, not independently compressed blocks.

This is a local ratio heuristic, not an optimal adaptive path. Changing a root changes subsequent model observations and boundaries, so shortest paths with fixed weights from C07 do not establish global optimality. A floating-point encoder decision may vary across architectures; the selected root sequence is explicitly coded and the decoder does not repeat the heuristic. The experiment records compiler and archive digests. If every heuristic loses, retain greedy. If gains justify further work, investigate limited lookahead or jointly trained static proxy costs. All candidate costs and header bytes are charged in actual archive size. No novelty or full-corpus claim.
