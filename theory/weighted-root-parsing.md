# Weighted root parsing in a fixed arithmetic dictionary

Each literal or dictionary expansion matching input at position i defines an edge i -> i+len with nonnegative fixed cost w(id). The resulting graph is acyclic and has a path via literal bytes. Let C(L)=0. Then C(i)=min over matching roots [w(id)+C(i+len(id))]. Backward induction proves exact shortest path; retain the minimizing root and reconstruct in forward order. A greedy longest match is not necessarily minimal root count: dictionary ab, abc, cd, ef, cdef and input abcdef gives greedy abc,d,ef but optimum ab,cdef. IXG2 trie stores the lowest ID for duplicate expansions; optimality applies to the available trie edges, not omitted duplicate aliases.

For fixed-width roots all weights equal and this minimizes root payload bits, hence the full fixed-width archive cost for the given dictionary. For Huffman roots the weights depend on the parse. Iteration using a smoothed frequency model gives a heuristic coordinate search; the exact shortest path only minimizes each fixed weighted objective, not jointly learned code lengths and metadata. Rebuild the actual unsmoothed Huffman tree for each candidate, charge its count table and padding, and retain the smallest measured archive including greedy. This guarantees no regression in actual frame size relative to greedy for these candidates. No claim of global Huffman/parse optimality or novelty.

The current bounded reference holds O(L) suffix costs and choices, plus roots, and caps input at 16 MiB. To scale exact fixed-weight DP: use reverse blocks of length B, retain the next D-1 suffix costs at each boundary (D=max expansion), recompute each block forward from stored boundary costs and right halo, and emit roots while allowing choices to cross boundaries. This yields the exact same optimum with O(B + ceil(L/B) D) memory and two passes over seekable input. Use 64-bit costs for full enwik9. Implementation and performance not yet verified. No arbitrary independent block grammars: the dictionary and shortest path remain global.
