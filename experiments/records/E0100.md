# E0100 — Lexical rank arithmetic intervals

M4 continuation. E0099 explicit products lose on 2176 sampled article fragments; preserve all exact products and unresolved cofactors, but change representation rather than increase factor bounds. E0100 constructs an exact rank sequence of lexical word/number/whitespace/punctuation tokens (64-byte maximum fragment). The fixed-width rank stream is a radix-2^k integer representation of the token sequence, preserving count; adaptive interval modes represent the same rank sequence using variable-width probability intervals. This is classical arithmetic coding at a new lexical scale, not a novel factorization theorem. XML article text and nonarticle spans get separate token streams, with an explicit ordered list of span kind and byte length; concatenation reconstructs the exact original page sequence. No normalization.

Train up to 4095 frequent tokens per stream on disjoint initial page-aligned region. Dictionary order, bytes, widths, escape lengths and bytes, rank count and length, mode, all span descriptors and header are charged in actual IXW1 archives. Three matched modes: fixed-width rank bits, global adaptive arithmetic interval model, adaptive interval conditioned on previous token class (letter/digit/whitespace/other/start). Deterministic priors from rank index, Fenwick cumulative counts, bounded rescale at 16384, 32-bit interval and exact JS integer arithmetic below 2^53. Escaped tokens preserve exact bytes and context. Decoder uses archive only; no corpus or trained external dictionary. Canonical rank/escape re-encoding, exact bytes, append/truncation rejection. Fixtures include empty, escaped bytes, truncated XML, dictionary-free, long repeated stream and rescaled model. Three reused E0099 held-out regions, exact matching raw hashes, gzip control. No DEFLATE in candidate; no claims about novel arithmetic, independent decoder, or whole corpus. This is not yet prime factoring of rank integers; first test whether useful token representation exists. If promising, further investigate phrase/sentence-conditioned rank or low-cost arithmetic subexpressions; otherwise assess alternatives. Standard hosted CI, 600s cap.
