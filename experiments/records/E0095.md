# E0095 — XML lexical span census and initial short-integer factors

Planned. Full enwik9 byte array (1 GB, deliberate bounded memory trade-off), lexical scanner recognizes start/end/empty tags, quoted attributes, comments, CDATA and processing instructions without entity expansion. Unsupported declarations/names or mismatched closing tags fail closed; incomplete EOF tag and open stack are retained. Current scanner is corpus-specific, not a general XML validator. Replay every disjoint token to a reconstructed file and compare complete bytes and SHA-256; this validates byte preservation, not yet an independently decoded compressed tree. Path-specific element spans (including tags) and plain leaf-body spans (excluding tags; no children or opaque lexical constructs) are counted separately; their aggregate byte counts overlap across hierarchy and must not be summed as a partition. Histogram buckets: 0, 1–8, 9–16, 17–32, 33–64, 65–256, 257–1024, 1025–4096, >4096. Report markup, text, opaque and partial bytes as disjoint totals, root count, maximum depth and open paths. Profile includes no entity normalization.

Factor study: deterministic reservoir of up to 16 short (1–8 byte) spans per path/kind, capped at 2048 cases overall. Deterministic 64-bit Miller–Rabin witnesses and bounded Pollard rho (32768 iterations per integer; <=8 constants, <=8192 steps each). Complete factors sorted, verified prime and exact product, serialized as one count byte plus canonical unsigned LEB128 prime and one exponent byte per distinct prime; independent-width reconstruction and malformed trailing rejection in unit tests. Compare payload bytes to original span length (common outer mode and width not included); local wins are only a screening result, never full archive savings. Leading zeros retained via span length; zero and one counted separately, incomplete factorization censored. All measured samples logged with offset, integer, factors and cost. No larger-integer factor claim yet. No owner downloads. Memory cap 6 GiB virtual, 480 s experiment timeout, 20 min hosted job. Four unit tests plus complete corpus cmp/hash.
