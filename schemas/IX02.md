# IX02 oracle format

Header: ASCII IX02, mode byte, u64 original length big-endian (13 bytes). Raw mode 0: exactly L input bytes. Mode 1: exponent (2..32), sign (0 add, 1 subtract), canonical unsigned LEB128 base-byte length, minimal big-endian base bytes, canonical unsigned LEB128 residual-byte length, minimal big-endian residual bytes. Zero magnitude is one zero byte; reject negative zero, base <2, trailing data and out-of-range N. Decode as N=base^exponent +/- residual and emit L bytes, including leading zeros. The oracle has a 16 MiB output cap and rejects arithmetic operands beyond its width guard; this is a research fixture, not a general unbounded decoder. Encoder selects smallest candidate payload among floor and ceil roots and raw. Strict net savings require total frame < L. Decoder costs excluded from experiment archive size; no contest claim.
