# IXT1 reversible transform frame

Magic IXT1, one transform ID byte, then all transformed bytes. Original length is inferred from frame length minus five. ID 0 identity. IDs 1..6 integer difference, 7..12 independent digit difference, 13..18 XOR difference; each uses lags 1,2,4,8,16,32 in order. IDs 19..21 integer, 22..24 digit, 25..27 XOR, each applied twice with lags 1,4,16. Treat input as big-endian, pad delayed digits beyond least significant end with zero. Integer transform is multiplication by (1-256^lag) modulo 256^L, including borrow across digit boundaries. Digit transform subtracts modulo 256 independently, XOR uses bitwise XOR. Inverse integrates from least significant end, adding delayed recovered digits and propagating carry only for integer mode. Repeat inverse twice for order 2. All selectors charged. Raw frame itself expands five bytes; downstream compression must be measured, not inferred from entropy. Frame unauthenticated.
