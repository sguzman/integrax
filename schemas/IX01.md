# IX01 format

Big-endian. Frame: ASCII IX01, mode byte, u64 original byte length, payload. Header costs 13 bytes.

Mode 0: exactly L raw bytes. Mode 1: for 1<=L<=16, one-byte base length (1..16), minimal unsigned base bytes, exponent byte (2..127), sign byte (0 add, 1 subtract), residual length byte (1..16), minimal unsigned residual bytes. Zero is one zero byte. Base >=2; negative zero invalid. Compute N=base^exponent +/- residual using checked u128, emit exactly L bytes with leading zeros. Reject overflow, nonminimal values, trailing bytes and out-of-range results. Encoder considers floor and ceil roots and retains strictly shorter payloads than raw. No external state. This is a tiny reference, not scalable arithmetic compression.
