# IXB1 context permutation frame

Magic IXB1 (4 bytes), mode u8 0..2, original length u64 BE (<=16 MiB), primary index u32 BE, payload. Empty input requires primary zero. Sort cyclic rotations lexicographically with starting-index tie break; output last column and index of rotation starting at zero. Mode0 raw last column. Mode1 MTF ranks, initial alphabet 0..255, move referenced byte to front. Mode2 additionally replace maximal zero runs with byte 0 followed by positive canonical unsigned LEB128 run length. Nonzero ranks literal. Reject adjacent run markers, noncanonical counts, length overflow, invalid primary. Restore MTF then inverse via stable last-to-first row permutation. All frame metadata is included. The frame is not self-compressing or authenticated; external backend may compress it, and actual complete outer archive size is charged. Decoder does not enforce BWT canonicality on arbitrary malformed columns.

## Native interval modes 3 and 4

Both begin with canonical BWT and MTF. Mode 3 codes each eight-bit rank using a binary prefix tree conditioned on previous rank bucket c=0 for rank zero, otherwise 1+floor(log2 rank), start c=0. Mode 4 codes a flag (1 means maximal zero run) with a separate adaptive pair conditioned on c. If zero run, code k=floor(log2 run_length) as k zero bits followed by 1, with separate adaptive counts for each unary position 0..24 and c, then k equiprobable bits of the binary suffix; reset c=0. Otherwise code rank minus 1 in the same binary rank tree and update c from actual rank. Reject rank offset 255, adjacent zero runs, exponent>24, overshoot. All adaptive pairs start (1,1), increment selected count, ceil-half both when sum>=4096. Interval arithmetic uses the IXG2 inclusive 32-bit E1/E2/E3 procedure and zero padding. Decoder regenerates payload from decoded rank sequence and requires exact equality, rejecting appended bytes; BWT column canonicality itself remains unchecked. No transmitted model. Frame header unchanged.
