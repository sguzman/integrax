# IX04 static arithmetic intervals

Archive: magic IX04 (4 bytes), original length u64 BE (8), 256 unsigned u16 BE frequencies (512), arithmetic payload bits MSB first, zero pad to byte boundary. Empty input has all-zero counts and no payload. Nonempty input requires sum in 1..32768. Each observed symbol gets one count plus floor(hist[i]*(32768-active)/L); other symbols get zero. Counts are charged in full (524-byte header).

The inclusive 32-bit interval [lo,hi] starts at [0,2^32-1]. For digit i with cumulative counts c, update hi=lo+floor(range*c[i+1]/total)-1, lo=lo+floor(range*c[i]/total). Standard E1/E2/E3 renormalization emits common prefix bits and defers underflow bits; termination emits one bit and complementary pending bits. Decoder initializes code with 32 bits and selects the unique positive-frequency interval containing scaled code. Up to 32 virtual zero bits after EOF are permitted. Reconstruction stops at original length. This reference format is not authenticated; external exact comparison and hashes are required, and trailing bytes are not rejected. Encoder/decoder stream in fixed-size buffers, model built in a separate input pass. This is conventional finite-precision arithmetic coding, not exact multinomial rank or novel theorem.

No raw fallback in IX04: all input sizes use the same grammar, even if expansion results. A future framed mode selector can add raw fallback. Full-file comparison includes all metadata.
