# IXG1 arithmetic DAG

Magic IXG1, canonical unsigned LEB128 L (<=16384), mode. Raw mode 0: exactly L bytes. Mode 1: L>0, canonical LEB128 alphabet count k (1..256), k ascending distinct byte literals, canonical LEB128 rule count n (<=512), canonical LEB128 root count r (1..L). Then one MSB-first bit stream of rule operands and roots, padded with zero low bits only. Rule i (0-based) defines symbol k+i as concatenation of two earlier symbols, both stored in ceil(log2(k+i)) bits. Each root is stored in ceil(log2(k+n)) bits. Width zero means the only ID is 0. Reject forward or out-of-range references, noncanonical alphabet, nonzero padding, wrong length, trailing data or expansion beyond L. Decoder stores node lengths and iteratively expands roots; no recursive call stack.

Each symbol denotes a pair (integer,length); concatenation (A,a),(B,b) maps to (A*256^b+B,a+b). Repeated references reuse arithmetic subexpressions. No hidden corpus or dictionary. Encoder repeatedly picks the maximum count nonoverlapping adjacent pair, tie by numeric pair ID, and accepts substitution only if exact grammar frame size strictly falls; stops after <=512 rules, or at the first nonimproving step. Final raw fallback. This greedy search does not optimize globally; width thresholds can prevent useful later merges. Format unauthenticated and bounded; no full-target claim.
