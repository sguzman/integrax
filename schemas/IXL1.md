# IXL1 finite-field recurrence

Magic IXL1, canonical unsigned LEB128 original length L (<=16384), mode byte. Raw mode 0: exactly L bytes. Recurrence mode 1: canonical unsigned LEB128 degree d (0..min(256,L)), d big-endian u16 coefficients in 0..256, then d raw seed bytes. No other bytes. For i>=d, x_i=sum_{j=1}^d c_j*x_(i-j) mod 257. Reject generated 256, invalid coefficients or length. Degree zero produces zeros. Leading zero digits preserved by length. All framing/coefficients/seed charged.

Encoder uses Berlekamp–Massey over F_257 to find minimum linear recurrence degree of observed prefix. Abort on degree >256 since finite-sequence minimum degree is nondecreasing under extension. If completed, use arithmetic mode only if its exact cost is strictly less than raw framing; check full generated bytes before accepting. No exception stream yet. Format is unauthenticated, not a contest submission.
