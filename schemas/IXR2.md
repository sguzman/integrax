# IXR2 normalized rational description

Magic IXR2, canonical unsigned LEB128 original byte length L (<=16384), mode. Raw mode 0: exactly L original bytes. Rational mode 1: canonical LEB128 numerator-byte length, minimal nonnegative big-endian numerator p; canonical LEB128 denominator-byte length, minimal positive big-endian denominator q; sign byte (0 positive or zero, 1 negative); minimal big-endian residual magnitude occupying remaining bytes. Zero literal occupies one byte. Require 0<=p<=q, gcd(p,q)=1, q bit length<=1024, no negative zero, valid output range. Reconstruct N=floor(256^L p/q)+r exactly and write L bytes, preserving leading zeros. Unauthenticated: some truncated residuals are valid different values. No external data.

Encoder considers exact ordinary continued-fraction convergents of N/256^L, starting with 0/1, at most 1024 steps and denominator bit length<=1024, plus 1/1. Strictly minimize actual serialized bytes over tested candidates and raw fallback; no claim of optimality over all rational approximants, semiconvergents or other grammars. Archive has charged metadata, numerator, denominator and residual. Reference cap, no full-corpus implementation.
