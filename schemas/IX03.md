# IX03 — Geometric template plus sparse corrections

Header: ASCII IX03, mode byte, u64 big-endian original length L (13 bytes). Raw mode 0 contains exactly L bytes. Mode 1 contains canonical unsigned LEB128 period p, p template bytes, canonical unsigned LEB128 correction count k, then k pairs of canonical unsigned LEB128 gap and replacement byte. Initial next index is 0; corrected index i=next+gap, then next=i+1. All indices are strictly increasing and in range, replacement must differ from template digit. Require 1<=p<=min(256,floor(L/2)), reject noncanonical varints, trailing bytes and malformed counts. Decode by repeating template to L bytes and applying corrections. This evaluates the whole-integer geometric sum identity in theory/geometric-sums.md without materializing large powers.

Encoder uses modal per-residue templates with smallest-byte tie break, searches p ascending and retains only strictly shorter payloads, preferring earlier mode/period on ties. It may prune by a lower bound on serialized candidate cost. Research search cap: 1 MiB; larger inputs up to 16 MiB use raw mode. Decoder output cap 16 MiB. Archive size includes all header, selectors, template and corrections. Executable cost measured separately. No contest eligibility claim.
