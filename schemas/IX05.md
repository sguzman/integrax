# IX05 first-order conditional arithmetic intervals

IX05 extends IX04 using one model for every previous byte (0..255) and one start context (256). The archive header is magic IX05, u64 BE original length, then 257 tables of 256 unsigned u16 BE frequencies in context order. Header cost: 131,596 bytes. Each table has the same bounded scaling rule as IX04, applied to observed transitions; empty contexts are zero. The initial context is 256 and after each symbol becomes that symbol. A nonempty stream never encounters an empty context under its own model. All model data is charged, not supplied by the decoder or learned from the original file.

One uninterrupted 32-bit arithmetic interval encodes the sequence, using the context-specific cumulative counts. Termination and padding are inherited from IX04. Decoder uses a precomputed inverse lookup per context (at most about 8 MiB). No raw fallback or authentication; malformed data may produce wrong bytes and trailing bytes are not rejected; external comparison is required. Finite precision conditional entropy coding is established prior art, not literal multinomial rank or a novelty claim. Full-file model is static, not an adaptive or blockwise model. Log ideal empirical transition entropy and scaled-model cross entropy for accounting; floating point is diagnostic only, not used in encode/decode decisions.
