# IXG2 global arithmetic DAG

Header: magic IXG2, mode byte (0 fixed-width roots, 1 Huffman roots), u64 BE original byte length (<=1,000,000,000), u16 BE rule count n<=1024, n pairs of u16 BE symbol IDs. IDs 0..255 are fixed byte literals; rule i defines 256+i by concatenating two earlier symbols. Each expansion <=256 bytes. All rules charged, including unused training rules. Mode 1 additionally stores one canonical unsigned LEB128 root frequency for each of the 256+n symbols. Build a binary Huffman tree using a min-heap keyed by (weight, minimum leaf ID, creation ID); first popped node is left/0, second right/1. Single leaf uses zero bits; empty stream has no tree. Fixed mode root width ceil(log2(256+n)). Bits MSB-first, final unused low bits zero. No extra payload length: decode roots until exactly original byte length, validate weighted frequency total and actual counts in Huffman mode, reject nonzero padding or trailing bytes. No external dictionary at decode.

Training: at most 64 KiB sample, repeated maximum-frequency nonoverlapping pair replacement among eligible expansions <=256, ties by ascending pair ID, <=1024 rules. All 256 byte literals always available. Encode with global trie longest match, ties by lowest existing ID for duplicate expansions, parse continuously across read-buffer boundaries. Two passes compute frequencies and then encode. Archive-only comparison; no raw fallback in this experimental format. Memory bounded by dictionary size, trie, Huffman tree and fixed buffers. Unauthenticated; external SHA-256 and exact comparison required. Ordinary dictionary/Huffman coding with arithmetic concatenation semantics, not new mathematics.
