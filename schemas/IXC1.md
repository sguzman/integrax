# IXC1 — CRT residue description

Magic IXC1, canonical unsigned LEB128 input byte length L <= 16384, mode byte. Mode 0 raw: exactly L bytes. Mode 1 requires L>0; let k=max(2,ceil((8L+1)/3)), B=2^k, moduli B,B-1,B+1. Store three residues in this order. Each field: tag byte, canonical unsigned LEB128 magnitude byte length, minimal unsigned big-endian magnitude (zero occupies one byte). Tag 0 literal r=z; tag 1 r=m-z (z>0); tags 2+2j or 3+2j reference earlier residue j<i and add/subtract z modulo current m. Require z<m, reject negative zero, invalid references, trailing bytes and result outside [0,256^L). Encoder picks shortest field independently given earlier true residues, ties retain earlier choice; compare complete frame against raw. No external dictionary. Unauthenticated. Bounded reference, not full-corpus implementation.
